# Quick-Start Guide

Hello, young aspiring **Sciborg** programmer! Welcome to *SciGuides*. 

This guide covers **everything** from downloading your code editor, to Git, to electronics, and finally; actually coding a robot able to compete in **FIRST® Robotics**. is meant to **compliment** the lessons shown in our beloved **JV Robotics Programming Course**. If you are not taking this course at the moment, it may be a little difficult for you to get started. No worries though! The internet is **your best friend**.

Here is an excerpt from our **AI and Internet Policy**. 

>*We highly encourage you guys to use the internet for any assignment we give you. Researching is one of the most important skills you’ll learn as a programmer. However, there are some limitations to this. Our robotics program is meant to educate and to be fun. If you get a **clanker** to do all of your work for you, robotics will be EXTREMELY boring for you (and you will not learn anything). There is some value in the work that we do, so **make sure you can take pride in your work**.*

Our in-class presentations and this guide are both ordered by **days**. Each day covers a set of topics, and conclude with a **homework assignment** in order to reinforce what is learned. This guide is meant to assist you for both homeworks and when you will eventually **code a robot**.

That's All! Goodluck on your endevours....

*Ankit Kumar and the Sciborgs Programming Department*
