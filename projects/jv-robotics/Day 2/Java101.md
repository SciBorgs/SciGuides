## What is a program?

A **program** is **an ordered list of instructions** that are done **one-after-the-other** by the computer. We write **programs** with **code**. It is **written** in text with a special set of rules called **Syntax** (this is like **grammer** and **punctuation** rules, but for code). Every program has to be **broken down** into commands that a **CPU** can run. These commands have to be in **binary** and are predefined **by the specific CPU that you are using** (ARM and x86 processors are coded differently for this reason).

> CPU Commands include things like **ADD** and **SUBTRACT**

## What is Java?

**Java** is a **language** that we write code in. Java utilizes **english** words in a syntax that is very reliant on **Curly Braces { }** to define when certain **segements of code** start/stop, **Parentheses ( )** for operations and math, and **SemiColons;** to end specific **commands**. This lets Java code **ignore indentation** (and spacing for that matter) in order to **make writing/editing code easier**. Java also manages and interacts with the computer's **memory** for us (**instead of us having to do it ourselves**), allowing us to **store** data easily.

```
class Robot {
	Drivetrain drive;
	Arm scoringArm;
	
	void goBoom() {
		Boom = True;
  }
} 
```

## How is Java code organized?

Java employs very popular code-organization technique called **Object-Oriented-Programming**. In this type of programming we split our **commands** and **stored data** into **classes** that are located in seperate **.java files**. The **stored data** in classes are called **Fields**, and the **commands** are put into **methods** (Methods are essentially a set of commands that make up one **action** that you can execute by calling them).
