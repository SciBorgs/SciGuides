# SciGuides

**Hello, esteemed programmer friend!** Welcome to *SciGuides*.

These guides cover **everything** from downloading VS Code, to Git, to electronics, to WPILIB® and finally; actually coding a robot able to compete in **the FIRST® Robotics Competition**. There are many different tabs that we have **on our side pane** that you can use to navigate through our plethora of guides. Have fun out there!
